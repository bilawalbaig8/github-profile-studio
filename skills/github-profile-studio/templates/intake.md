# Profile intake

Copy this into a private working brief; replace prompts with the user's answers. Begin with unanswered questions before visual concepts unless a complete approved brief already exists.

- Outcome and audience: Who should visit, and what should they do next?
- Identity and destination: GitHub username, repository URL, branch, and ownership/access.
- Public background: LinkedIn link; if unavailable, permitted export or pasted facts.
- Content: Verified role, interests, featured repositories, desired sections, contact links.
- Visual direction: Two or three liked examples; preferred illustration style and things to avoid.
- Identity branch: Portrait or abstract/no-face? For portrait: reference photos, likeness permission, clothing, expression, pose, text side, and gaze. For abstract: symbols, textures, composition, and orientation; approve an identity board instead of a face sheet.
- Privacy: May generated likeness be public? May originals be uploaded? Where may photos be processed? Retain/delete inputs after delivery?
- Palette: Preferences and accessibility needs; visible boards will follow before selection.
- Motion: Static only or optional animation? Motion sensitivities, size budget, target devices.
- Deliverables: Editable format the user can open, timeline, existing assets, licensing.
- Publication: Local draft only, PR, or direct update? Exact repository/files/visibility covered by current authorization?

# Design brief

Use after intake. A blank approval field means pending, never implied consent.

| Decision | Agreed value | Evidence/approval |
| --- | --- | --- |
| Audience and primary action | | |
| Portrait or abstract/no-face branch | | |
| Illustration style and face references | | |
| Character sheet or abstract identity-board artifact/version | | |
| Pose, expression, gaze, text side | | |
| Palette preview artifact and chosen hex values | | |
| Typography and license/substitutions | | |
| README sections and verified copy | | |
| Native editable format and layer plan | | |
| Static export sizes and budget | | |
| Motion, duration and frame rate | | |
| Static/reduced-motion presentation | | |
| Public file manifest and destination | | |

Keep generation prompts tied to the approved sheet/board, pose/orientation, palette, and layout. Mark portrait-only fields not applicable for abstract/no-face work. For revisions, list which approval changes and show the changed artifact again before dependent final work.

# Contributing

Keep the skill agent-neutral and usable without a paid service. Describe optional tool capabilities without inventing tool names or claiming universal support.

Use fictional identities in examples. Do not submit photos, personal exports, credentials, career histories, or generated artwork derived from a real person without suitable permission. Ignored folders are a convenience, not a substitute for reviewing staged files.

Explain the user-visible problem and the change in a pull request. Run `python scripts/validate_project.py`, review local Markdown links, and exercise any changed helper. For workflow changes, include a brief simulated intake or revision scenario showing that approvals and missing facts remain explicit. Do not perform live publication as a test.
